Kalkulus adalah cabang matematika yang mempelajari perubahan dan akumulasi secara kontinu. Dikembangkan secara independen oleh Isaac Newton dan Gottfried Wilhelm Leibniz pada abad ke-17, kalkulus menjadi fondasi utama dalam fisika, teknik, ekonomi, dan berbagai bidang sains modern. Dengan memahami kalkulus, mahasiswa mampu memodelkan fenomena nyata seperti kecepatan gerak benda, pertumbuhan populasi, hingga optimasi sistem yang kompleks.

## Limit

Limit adalah fondasi dari seluruh kalkulus. Secara intuitif, limit menggambarkan nilai yang didekati oleh suatu fungsi ketika variabel bebasnya mendekati suatu titik tertentu — tanpa harus tepat berada di titik tersebut. Konsep ini memungkinkan kita mendefinisikan turunan dan integral secara formal.

Notasi limit dibaca: *"limit f(x) saat x mendekati a sama dengan L"*, yang berarti nilai f(x) semakin dekat ke L ketika x semakin mendekati a.

```math
\lim_{x \to a} f(x) = L
```

### Sifat-Sifat Limit

Beberapa sifat penting yang berlaku untuk limit fungsi:

```math
\lim_{x \to a} [f(x) + g(x)] = \lim_{x \to a} f(x) + \lim_{x \to a} g(x)
```

```math
\lim_{x \to a} [f(x) \cdot g(x)] = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x)
```

```math
\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)}, \quad \text{asalkan } \lim_{x \to a} g(x) \neq 0
```

### Limit Trigonometri Penting

Dua limit trigonometri yang sering digunakan dalam kalkulus lanjut:

```math
\lim_{x \to 0} \frac{\sin x}{x} = 1
```

```math
\lim_{x \to 0} \frac{1 - \cos x}{x} = 0
```

<Accordion title="Contoh Perhitungan Limit">
  Hitunglah nilai limit berikut:

  ```math
  \lim_{x \to 2} \frac{x^2 - 4}{x - 2}
  ```

  **Penyelesaian:** Faktorkan pembilang terlebih dahulu.

  ```math
  \frac{x^2 - 4}{x - 2} = \frac{(x-2)(x+2)}{x-2} = x + 2
  ```

  Sehingga:

  ```math
  \lim_{x \to 2} (x + 2) = 4
  ```
</Accordion>

## Turunan (Diferensial)

Turunan atau diferensial mengukur **laju perubahan sesaat** suatu fungsi terhadap variabelnya. Secara geometri, turunan f'(x) pada suatu titik merupakan gradien garis singgung kurva y = f(x) di titik tersebut. Turunan sangat penting dalam menyelesaikan masalah optimasi, analisis gerak, dan pemodelan perubahan dinamis.

Definisi turunan berdasarkan limit adalah sebagai berikut:

```math
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
```

### Aturan-Aturan Turunan

<Steps>
  <Step title="Aturan Pangkat (Power Rule)">
    Aturan paling dasar untuk menurunkan fungsi pangkat:

    ```math
    \frac{d}{dx} x^n = n \cdot x^{n-1}
    ```

    **Contoh:** Turunan dari $x^3$ adalah $3x^2$.
  </Step>
  <Step title="Aturan Perkalian (Product Rule)">
    Digunakan saat dua fungsi saling dikalikan:

    ```math
    \frac{d}{dx} [f(x) \cdot g(x)] = f'(x) \cdot g(x) + f(x) \cdot g'(x)
    ```
  </Step>
  <Step title="Aturan Pembagian (Quotient Rule)">
    Digunakan saat satu fungsi dibagi fungsi lain:

    ```math
    \frac{d}{dx} \left[\frac{f(x)}{g(x)}\right] = \frac{f'(x) \cdot g(x) - f(x) \cdot g'(x)}{[g(x)]^2}
    ```
  </Step>
  <Step title="Aturan Rantai (Chain Rule)">
    Digunakan untuk menurunkan fungsi komposisi:

    ```math
    \frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)
    ```
  </Step>
</Steps>

### Turunan Fungsi-Fungsi Umum

```math
\frac{d}{dx} \sin x = \cos x, \qquad \frac{d}{dx} \cos x = -\sin x
```

```math
\frac{d}{dx} e^x = e^x, \qquad \frac{d}{dx} \ln x = \frac{1}{x}
```

## Integral

Integral adalah operasi kebalikan dari turunan dan merupakan alat utama untuk menghitung **akumulasi** suatu besaran. Integral terbagi menjadi dua jenis: integral tak tentu (antiturunan) yang menghasilkan keluarga fungsi, dan integral tentu yang menghasilkan nilai numerik dan merepresentasikan luas di bawah kurva.

### Integral Tak Tentu

```math
\int f(x)\, dx = F(x) + C, \quad \text{di mana } F'(x) = f(x)
```

Konstanta C disebut **konstanta integrasi** dan mencerminkan bahwa ada tak hingga banyak antiturunan untuk setiap fungsi.

### Rumus Integral Dasar

```math
\int x^n\, dx = \frac{x^{n+1}}{n+1} + C, \quad n \neq -1
```

```math
\int e^x\, dx = e^x + C
```

```math
\int \frac{1}{x}\, dx = \ln|x| + C
```

```math
\int \sin x\, dx = -\cos x + C, \qquad \int \cos x\, dx = \sin x + C
```

### Integral Tentu dan Teorema Dasar Kalkulus

Teorema Dasar Kalkulus menghubungkan integral tentu dengan antiturunan:

```math
\int_a^b f(x)\, dx = F(b) - F(a)
```

<Accordion title="Contoh Perhitungan Integral Tentu">
  Hitunglah luas daerah di bawah kurva $f(x) = x^2$ dari $x = 0$ hingga $x = 3$.

  ```math
  \int_0^3 x^2\, dx = \left[\frac{x^3}{3}\right]_0^3 = \frac{27}{3} - \frac{0}{3} = 9
  ```

  Luas daerah tersebut adalah **9 satuan luas**.
</Accordion>

<Tip>
  **Strategi Belajar Kalkulus yang Efektif**

  Kalkulus membutuhkan latihan konsisten, bukan sekadar menghafal rumus. Mulailah dengan memahami konsep limit secara intuitif sebelum masuk ke turunan dan integral. Kerjakan soal dari yang paling sederhana secara bertahap, dan jangan lewatkan pembuktian rumus dasar agar pemahamanmu lebih mendalam. Gunakan grafik untuk memvisualisasikan setiap konsep — ini sangat membantu dalam memahami makna geometri dari turunan dan integral.
</Tip>

<Note>
  **Prasyarat Mata Kuliah**

  Sebelum mempelajari kalkulus, pastikan kamu telah menguasai materi **aljabar dasar** (persamaan, pertidaksamaan, fungsi), **trigonometri** (sudut, fungsi sin/cos/tan dan identitasnya), serta **geometri koordinat** (garis, parabola, lingkaran). Pemahaman yang kuat atas prasyarat ini akan membuat perjalananmu belajar kalkulus jauh lebih lancar.
</Note>
